String Methods

(len(var_name)) - for measuring length of a string, useful for limiting user input and whatnot

var_name.upper() - Forces an Uppercase Result
var_name.lower() - Forces a Lowercase Result
var_name.find('Insert str here') - Finds if a character exists on a string. returns a -1 if not found #Finds the index, while in returns the boolean value
var_name.replace("Insert what you want replaced", "Insert replacement u want to show") - Replacing a specific word
"specific word" in var_name - Finds a specific word in the variable and returns a Boolean Value (True or False) #Case sensitive btw 
var_name.title() - Makes every first Letter of every word Capital
var_name.capitalize() - Makes only the first Letter capital not every word
