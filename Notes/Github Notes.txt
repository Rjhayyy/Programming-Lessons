GITHUB START
OPEN GIT CMD

Code -> git add(Stage) -> (commit)


Bash - Terminal of Git
CMD - Terminal of Windows

cd - go to folder
cd .. - Go back folder
cd tab(KEYBOARD BUTTON) - Fast keywords
pwd - Check what directory you are in
ls - check directory(Bash)
ls -a = Shows hidden files
code . - OPEN VSCODE

Go to desktop first to make directory
"cd desktop"

Make Folder using CMD
"mkdir (name)"

Initialize git(ALWAYS DO THIS WHEN DOING NEW PROJECTS)
"git init"

Staging - ALWAYS DO THIS BEFORE COMMITING
"git add"
git add --all = Stage everything inside the project
git add . = Stage the current directory you are in
git add * - Stages all visible changes except deleted files

git status - "checks the status/changes of the directory" "Can also check what is currently staged"

git commit -m "IMPORTANT COMMENTS/MESSAGE" = Push to the local main repo 

git push - PUT IN ONLINE MAIN REPO

git reset - unstage everything
git reset HEAD~ - unstage and go back 1 commit
git reset --hard - Brings back deleted files ITS BASICALLY A HARD RESET

Clone - Copies from online repo to local repo
"git clone (HTTPS LINK)"

git rm (File_Name) - Removes files and automatically stage the changes 
git rm -f (File_Name) - Forcefully removes the File and stage the changes
git rm --cached (File_Name) - Removes the file from the stage but keep the physical file
git rm (Folder_Name) - Removes the folder only but not the contents
git rm -r (Folder_Name) - Removes the whole folder and its contents

git log - See's the detailed push history
git log --oneline = Cleaner way of seeing the push history but less detailed

git branch - checks for current branches
git branch (Branch Name) - creates a branch
git checkout (Branch Name) - Accesses the Branch
